# Yandex Alice Video Bot

Автоматизация создания видео из фотографий через Yandex Alice Media Video с помощью Playwright.

## Возможности

* Автоматически обрабатывает все фотографии из указанной папки.
* Загружает изображения в Yandex Alice Video.
* Случайным образом выбирает один из доступных сюжетов.
* Запускает генерацию видео.
* Ожидает завершения обработки.
* Скачивает готовое видео в отдельную папку.
* Использует сохранённую сессию Яндекс-аккаунта.
* Последовательно обрабатывает все изображения до окончания списка.

---

## Требования

* Python 3.10 или выше
* Playwright
* Chromium Browser

---

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/ВАШ_ЛОГИН/yandex-alice-video-bot.git
cd yandex-alice-video-bot
```

Установите зависимости:

```bash
pip install -r requirements.txt
playwright install chromium
```

---

## Авторизация в Яндекс

Перед первым запуском необходимо сохранить сессию Яндекс-аккаунта.

Запустите:

```bash
python login.py
```

После открытия браузера:

1. Войдите в свой Яндекс-аккаунт.
2. Убедитесь, что открылась страница Alice Video.
3. Вернитесь в консоль.
4. Нажмите Enter.

После этого сессия будет сохранена локально и повторная авторизация не потребуется.

## Настройка

В файле `main.py` укажите необходимые пути:

```python
INPUT_DIR = Path(r"C:\photos")
OUTPUT_DIR = Path(r"C:\videos")
PROFILE_DIR = Path(r"C:\yandex_alice_profile")
```

### INPUT_DIR

Папка с исходными фотографиями.

### OUTPUT_DIR

Папка для сохранения готовых видео.

### PROFILE_DIR

Папка, в которой хранится браузерный профиль и авторизация Яндекса.

## Возможные проблемы

### Скрипт не может загрузить изображение

После обновления интерфейса Яндекс некоторые селекторы могут измениться. В этом случае потребуется обновить селекторы Playwright.

### Видео долго генерируется

Время ожидания зависит от нагрузки на серверы Яндекса и может составлять от нескольких секунд до нескольких минут.

### Требуется повторная авторизация

Удалите папку профиля:

```text
yandex_alice_profile/
```

и снова выполните:

```bash
python login.py
```
